# Image Placeholders

## Logo
Place your Project GreenGuard logo at:
- `public/logo.png` (recommended: 64x64px or larger, transparent background)

## Feature Icons
Place feature icons in the `public/icons/` directory:

- `public/icons/iot-monitoring.svg` - Real-Time IoT Monitoring icon
- `public/icons/nasa-integration.svg` - NASA FIRMS Integration icon
- `public/icons/ai-assessment.svg` - AI-Powered Risk Assessment icon
- `public/icons/dashboard.svg` - Interactive Dashboard icon
- `public/icons/warning-system.svg` - Early Warning System icon
- `public/icons/cloud-infrastructure.svg` - Cloud Infrastructure icon

### Icon Specifications
- Format: SVG (preferred) or PNG
- Size: 64x64px minimum
- Style: Simple, clean icons that match the design aesthetic
- Color: Can be colored or monochrome (will inherit text color)

## Fallback Behavior
If images are not found, placeholder boxes will be displayed automatically. The placeholders are styled to match the design and provide a clean fallback experience.
